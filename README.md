# 🎓 Расшифровка занятий — запись звука онлайн-урока в текст

Локальная программа для Windows 10/11: пишет **системный звук** (собеседник в
Zoom / Яндекс.Телемост / Discord) и **ваш микрофон**, а после нажатия «Стоп»
превращает запись в обычный текстовый файл.

* 🔒 **Всё на вашем компьютере.** Никаких облаков, аккаунтов и отправки данных.
* 💸 **Полностью бесплатно.** Только открытые библиотеки (soundcard,
  faster-whisper, customtkinter).
* 🔌 **Без виртуальных аудиокабелей.** Системный звук берётся через WASAPI
  loopback — это встроенный механизм Windows, ничего дополнительно ставить не
  нужно.
* 🇷🇺 **Русский язык распознаётся явно** (`language="ru"`), модель `medium` по
  умолчанию (можно переключить на `small`, если компьютер слабый).

---

## 1. Что нужно один раз установить

Порядок важен, поэтому идите по шагам сверху вниз. На всё уйдёт 15–30 минут
(основное время — скачивание модели распознавания при первом запуске).

### Шаг 1. Python 3.10 – 3.13

1. Откройте <https://www.python.org/downloads/windows/>.
2. Скачайте **Python 3.12.x — Windows installer (64-bit)** (подойдёт 3.10–3.13;
   Python 3.14 пока не рекомендуется — часть библиотек к нему ещё не готова).
3. Запустите установщик и **обязательно** поставьте галочку
   **«Add python.exe to PATH»** внизу первого окна, затем нажмите
   **Install Now**.
4. Проверьте установку: нажмите `Win + R`, введите `cmd`, нажмите Enter и в
   чёрном окне наберите:

   ```
   python --version
   ```

   Должно ответить что-то вроде `Python 3.12.7`. Если вместо этого открылся
   Microsoft Store или написано «не является внутренней или внешней командой»,
   переустановите Python с галочкой PATH.

> **Если при установке не было галочки «tcl/tk and IDLE»** (она включена по
> умолчанию) — окно программы не запустится. Запустите установщик ещё раз,
> выберите *Modify* и включите эту галочку.

### Шаг 2. FFmpeg

FFmpeg нужен только для декодирования «чужих» аудиоформатов (mp3, m4a, ogg),
если вы захотите расшифровать готовый файл. Запись, сделанная самой программой,
расшифровывается без него. Но поставить его стоит — это 5 минут.

1. Откройте <https://www.gyan.dev/ffmpeg/builds/> и скачайте
   **`ffmpeg-release-essentials.zip`** (раздел *release builds*).
2. Распакуйте архив, например в `C:\ffmpeg`. Внутри должна появиться папка
   `bin`, а в ней файлы `ffmpeg.exe`, `ffprobe.exe`.
   Итоговый путь должен быть таким: `C:\ffmpeg\bin\ffmpeg.exe`.
3. Пропишите папку в PATH:
   1. Нажмите `Win`, начните вводить **«Изменение системных переменных среды»**
      (англ. *Edit the system environment variables*) и откройте найденный пункт.
   2. Кнопка **«Переменные среды…»** (*Environment Variables…*).
   3. В верхнем блоке выберите строку **Path** → **«Изменить…»** (*Edit…*) →
      **«Создать»** (*New*) → вставьте `C:\ffmpeg\bin` → **ОК** во всех окнах.
4. Проверьте: закройте `cmd` (если был открыт), откройте его снова и наберите:

   ```
   ffmpeg -version
   ```

   Должна появиться строка с версией (`ffmpeg version 7.x ...`).

### Шаг 3. Библиотеки программы

1. Скачайте папку с программой (например, распакуйте архив в
   `C:\TutorTranscript`).
2. Откройте эту папку в Проводнике, щёлкните по адресной строке, наберите
   `cmd` и нажмите Enter — откроется консоль уже в нужной папке.
3. Выполните:

   ```
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```

   Установка скачает около 300 МБ (faster-whisper тянет CTranslate2 и PyAV).
   Если pip ругается на старую версию — выполните
   `python -m pip install --upgrade pip` и повторите.

**Альтернатива без командной строки:** просто дважды щёлкните по
`run_windows.bat` — он сам создаст окружение, поставит библиотеки и запустит
программу. Первый запуск будет долгим, дальше — мгновенным.

## 2. Запуск

Дважды щёлкните **`run_windows.bat`** (или `start.pyw` — без чёрного окна
консоли), либо в консоли:

```
venv\Scripts\python main.py
```

Вы увидите окно с тремя кнопками: **Старт**, **Пауза**, **Стоп и расшифровать**.

---

## 3. Как пользоваться на занятии

1. **Проверьте источники.** В блоке «Источники звука» выберите
   *Звук компьютера* (loopback-устройство ваших динамиков/наушников) и
   *Микрофон*. Обычно программа выбирает их сама.
2. **Проверьте уровни.** Скажите пару слов и включите любое видео: полоски
   «Уровень микрофона» и «Уровень звука ПК» должны шевелиться. Если полоска
   стоит на нуле — нажмите «⟳ Обновить устройства» и выберите другое устройство.
3. **Нажмите «Старт»** в начале занятия.
4. **«Пауза»** — если нужно отойти или обсудить что-то не для записи (звук в
   файл не попадает, таймер продолжает идти). Повторное нажатие — продолжить.
5. **«Стоп и расшифровать»** в конце занятия. Программа сама:
   * создаст `.txt` с датой и временем окончания, например
     `transcript_2026-11-09_18-30-00.txt`;
   * положит его в папку «Документы» (или в папку, которую вы выбрали кнопкой
     «Выбрать…» в блоке «Расшифровка и сохранение»);
   * покажет прогресс распознавания и время до конца.

Расшифровка идёт медленнее реального времени на слабых процессорах: примерно
×0,3–1,0 от длительности занятия для модели `medium` на современном CPU.
Можно свернуть окно и заниматься своими делами — программа сама подаст
звуковой сигнал и покажет кнопку «Открыть расшифровку».

> **Первый запуск — самый долгий:** модель `medium` (~1,5 ГБ) скачивается с
> Hugging Face один раз и хранится в
> `%APPDATA%\TutorTranscript\models`. Поэтому перед первым занятием запустите
> программу, нажмите «Старт», через 5 секунд «Стоп» и дождитесь окончания
> загрузки модели — дальше всё будет работать без интернета.

## 4. Если модель работает слишком медленно

В блоке «Расшифровка и сохранение» переключите **Модель** с `medium` на
`small`. Скорость вырастет в 2–3 раза, качество на русском языке немного
снизится (пропадают редкие термины, чаще путаются окончания). Изменение
сохраняется — при следующем запуске будет использоваться выбранная модель.

| Модель | Размер | Скорость на CPU (ориентир) | Качество на русском |
| --- | --- | --- | --- |
| `small` | ~480 МБ | ~×1,0 от реального времени | хорошее |
| `medium` (по умолчанию) | ~1,5 ГБ | ~×0,4 от реального времени | очень хорошее |
| `large-v3` | ~3 ГБ | ~×0,15 | отличное (нужен мощный ПК/видеокарта) |

Точные цифры зависят от процессора. Если у вас видеокарта NVIDIA — программа
автоматически попробует использовать её (`float16`), это в 5–10 раз быстрее.

Дополнительно ускорить распознавание можно в файле настроек (см. ниже),
уменьшив `beam_size` с `5` до `1`.

## 5. Где лежат файлы и настройки

| Что | Где |
| --- | --- |
| Расшифровки | «Документы» или папка, выбранная в программе |
| Временная запись (`*.wav`) | `%APPDATA%\TutorTranscript\temp\` — удаляется после расшифровки |
| Настройки | `%APPDATA%\TutorTranscript\settings.json` |
| Журнал ошибок | `%APPDATA%\TutorTranscript\app.log` |
| Модели распознавания | `%APPDATA%\TutorTranscript\models\` |

Чтобы открыть `%APPDATA%\TutorTranscript`, нажмите `Win + R` и вставьте
`%APPDATA%\TutorTranscript`.

**Галочка «Сохранять и аудиозапись (WAV) рядом с текстом»** оставляет ещё и
звук занятия — удобно, если расшифровку нужно перепроверить.

Файл `settings.json` можно править вручную (программа читает его при запуске):

```json
{
  "model_size": "medium",
  "language": "ru",
  "capture_mode": "both",
  "beam_size": 5,
  "vad_filter": true,
  "output_dir": "D:\\Уроки\\Расшифровки",
  "keep_audio": false,
  "appearance": "dark"
}
```

* `capture_mode`: `both` (микрофон + системный звук), `system`, `mic`.
* `language`: `ru`, `en` или `auto` (определять автоматически).
* `beam_size`: `1` — быстрее, `5` — точнее.
* `vad_filter`: `false` отключает вырезание пауз (иногда точнее на тихой речи).

## 6. Частые проблемы и что делать

Сначала запустите проверку окружения — она печатает всё, что нужно для
диагностики:

```
venv\Scripts\python diagnostics.py
```

И проверку записи (5 секунд, с сохранением пробного WAV):

```
venv\Scripts\python main.py --self-test
```

| Симптом | Причина и решение |
| --- | --- |
| «Не хватает библиотек…» при запуске | Не выполнена установка зависимостей: `pip install -r requirements.txt` в активированном окружении. |
| `python` не найден | Python установлен без галочки PATH — переустановите с «Add python.exe to PATH». |
| Пустой список «Звук компьютера» | В системе нет активного воспроизведения. Включите любое видео/звонок и нажмите «Обновить устройства». Если не помогает — проверьте в `diagnostics.py` строку `LOOPBACK`; при её отсутствии программа автоматически переключится на резервный способ (WASAPI через sounddevice). |
| В записи только мой голос (или только собеседник) | Выбран неправильный источник. Раскройте список устройств: *Звук компьютера* — это динамики/наушники (loopback), *Микрофон* — гарнитура. Проверьте полоски уровня. |
| Полоски уровня стоят на нуле | Микрофон занят или выключен в «Параметры → Система → Звук»; проверьте разрешение для приложений. Для системного звука — увеличьте громкость. |
| Запись «не слышит» собеседника в наушниках | Это нормально: loopback дублирует именно то, что уходит в наушники. Если человек говорит очень тихо — поднимите громкость в настройках звонка (она влияет на запись). |
| Первое «Стоп» висит долго | Скачивается модель (1,5 ГБ). Смотрите журнал в окне — там написано «Загрузка модели…». Нужен интернет только в первый раз. |
| Распознавание идёт часами | Переключите модель на `small`, уменьшите `beam_size` до `1`, закройте лишние программы. Видеокарта NVIDIA сильно ускоряет процесс. |
| «Речь не распознана» | Запись почти тихая или содержит только шум. Проверьте уровни, убедитесь, что микрофон не был на паузе/выключен. |
| Текст получается «не по-русски», с латиницей | Убедитесь, что в `settings.json` `"language": "ru"` (по умолчанию так). |
| Окно не открывается, ошибка про `tkinter` | Python установлен без tcl/tk — запустите установщик, *Modify*, включите «tcl/tk and IDLE». |
| Программа упала / закрылась | Откройте `%APPDATA%\TutorTranscript\app.log` — последние строки описывают причину. |

## 7. Как это устроено

```
┌──────────────────┐   WASAPI loopback    ┌───────────────┐
│ Звук компьютера  │ ───────────────────► │               │
│ (Zoom, Телемост) │                      │  смешивание   │
└──────────────────┘                      │  по блокам    │
┌──────────────────┐                      │  0,2 с        │
│ Микрофон         │ ───────────────────► │               │
└──────────────────┘                      └───────┬───────┘
                                                  │ 16 кГц, моно, WAV
                                                  ▼
                                   ┌──────────────────────────┐
                                   │ faster-whisper (medium)  │
                                   │ language="ru"            │
                                   │ без меток времени        │
                                   └────────────┬─────────────┘
                                                ▼
                              transcript_2026-11-09_18-30-00.txt
```

* **soundcard** (`mediafoundation` бэкенд) открывает loopback-копию динамиков и
  микрофон как два независимых «микрофона» WASAPI. Виртуальные кабели не нужны.
* Каждый источник читается в **своём потоке** блоками по 0,2 с. Блоки
  синхронизируются по счётчику: если один источник отстал, его данные
  дополняются тишиной, поэтому рассинхронизация не накапливается даже на
  трёхчасовом занятии.
* Смесь пишется сразу в WAV (16 кГц, моно, 16 бит) с обновлением заголовка —
  файл остаётся валидным, даже если компьютер выключился во время записи.
* **Пауза** не останавливает чтение устройства, а просто перестаёт писать
  блоки в файл — после продолжения запись идёт без «щелчков».
* После «Стоп» WAV отдаётся **faster-whisper** как массив NumPy, поэтому
  FFmpeg для декодирования не требуется. Сегменты склеиваются в сплошной
  текст: точка → новый абзац, длинные строки переносятся по словам.
* Если `soundcard` не смог открыть loopback (экзотический драйвер), включается
  **резервный путь** — `sounddevice` + WASAPI loopback с автоматической
  передискретизацией 48 → 16 кГц (`FallbackSource` в `capture.py`).

### Файлы проекта

| Файл | Назначение |
| --- | --- |
| `main.py` | точка входа, проверки окружения, режимы `--self-test` и `--console` |
| `start.pyw` | запуск без консольного окна (Windows) |
| `run_windows.bat` | установка «в один клик» и запуск |
| `diagnostics.py` | проверка окружения и списка устройств |
| `tutor_transcript/config.py` | настройки, пути, журнал |
| `tutor_transcript/devices.py` | поиск loopback-устройств и микрофонов, выбор по умолчанию |
| `tutor_transcript/audio_sink.py` | запись WAV, смешивание, передискретизация |
| `tutor_transcript/capture.py` | источники звука, синхронизация, пауза, fallback |
| `tutor_transcript/transcriber.py` | faster-whisper, склейка текста, сохранение `.txt` |
| `tutor_transcript/gui.py` | окно на customtkinter |
| `tests/` | 49 автотестов (логика, GUI без Tk, интеграция записи) |

### Для разработчика

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python -m unittest discover -s tests -v
```

Тесты не требуют звуковой карты: источники подменяются искусственными
сигналами, модель распознавания — заглушкой, `customtkinter` — простыми
объектами. Поэтому их можно запускать на любом компьютере и в CI.

## 8. Полезные команды

```
venv\Scripts\python main.py                 # обычный запуск с окном
venv\Scripts\python main.py --self-test     # проверить запись (5 секунд)
venv\Scripts\python main.py --console       # без окна: запись до Enter и расшифровка
venv\Scripts\python main.py --model small   # разово взять другую модель
venv\Scripts\python main.py --debug         # подробный журнал
venv\Scripts\python diagnostics.py          # проверить окружение и устройства
venv\Scripts\python -m unittest discover -s tests   # автотесты
```

Пример готовой расшифровки (со служебной шапкой) — в файле
[`examples/transcript_2026-11-09_18-30-00.txt`](examples/transcript_2026-11-09_18-30-00.txt).

## 9. Приватность

Программа не отправляет звук и текст никуда. В интернет она обращается только
один раз — чтобы скачать модель распознавания с Hugging Face (это официальный
репозиторий проекта faster-whisper). После загрузки модели интернет не нужен
совсем: занятие можно проводить в самолёте.
