# 🎓 Расшифровка занятий — запись урока и быстрый текст

Три кнопки: **Старт**, **Пауза**, **Расшифровка**. Программа пишет звук
компьютера (собеседник в Zoom / Яндекс.Телемост) вместе с вашим микрофоном,
а по нажатию «Расшифровка» сохраняет сплошной текст на рабочий стол.

* ⚡ **Час занятия расшифровывается за 2,5–3 минуты** на модели `base`
  (4-ядерный процессор; на 8+ ядрах — быстрее).
* 🔒 **Всё локально.** Никаких облаков, аккаунтов и отправки данных.
* 🔌 **Без виртуальных кабелей.** Звук компьютера берётся через WASAPI loopback
  — встроенный механизм Windows.
* 🖱 **Ничего не настраивается.** Устройства выбираются сами, модель — `base`,
  папка — `C:\Users\TREIDCOMPUTERS\Desktop`.

---

## 1. Установка (один раз)

### Шаг 1. Python 3.10–3.13

1. Откройте <https://www.python.org/downloads/windows/>.
2. Скачайте **Python 3.12.x — Windows installer (64-bit)**.
3. Запустите установщик и **обязательно** отметьте галочку
   **«Add python.exe to PATH»**, затем нажмите **Install Now**.
4. Проверка: `Win + R` → `cmd` → Enter, наберите:

   ```
   python --version
   ```

   Должно ответить, например, `Python 3.12.7`.

> Галочку **«tcl/tk and IDLE»** в установщике снимать нельзя — без неё не
> откроется окно программы.

### Шаг 2. Библиотеки

Самый простой путь — двойной щелчок по **`run_windows.bat`**. Он сам создаст
окружение, поставит библиотеки и запустит программу (первый запуск — несколько
минут, дальше — сразу).

Если хотите вручную, откройте консоль в папке программы
(щёлкните по адресной строке Проводника, наберите `cmd`, Enter) и выполните:

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
venv\Scripts\python main.py
```

### Шаг 3. FFmpeg — не нужен

Программа записывает звук сразу в формат, который понимает модель
распознавания (16 кГц, моно, WAV), поэтому FFmpeg для работы **не требуется**.
Он понадобится только если вы когда-нибудь захотите расшифровать чужой
файл `.mp3` — но такой функции в этой версии нет.

## 2. Как пользоваться

1. Двойной щелчок по **`run_windows.bat`** (или `start.pyw` — без чёрного окна
   консоли).
2. Нажмите **Старт** в начале занятия. На экране идёт таймер.
3. **Пауза** — если нужно прерваться (звук в файл не попадёт). Повторное
   нажатие продолжает запись.
4. **Расшифровка** в конце занятия. Программа остановит запись и сохранит текст:

   ```
   C:\Users\TREIDCOMPUTERS\Desktop\transcript_2026-11-09_18-30-00.txt
   ```

   Кнопка «Открыть последний текст» покажет файл в Проводнике.

Первые 10–20 секунд после запуска программа молча загружает модель
(`base`, ~145 МБ) — это происходит один раз, дальше модель берётся из памяти.
Скачивание нужно только при самом первом запуске: после этого интернет не
требуется вообще.

### Во время расшифровки

В окне видно, сколько уже распознано и с какой скоростью:

```
Распознано 00:41:20 из 01:00:00 (×22 к реальному времени)
```

По этой строке легко понять запас: ×20 и выше — час уложится в 3 минуты.

## 3. Что именно ускоряет расшифровку

| Приём | Что делает | Выигрыш |
| --- | --- | --- |
| `BatchedInferencePipeline`, `batch_size=8` | модель обрабатывает 8 фрагментов по 30 с за один вызов — все ядра заняты | ×2–4 |
| `beam_size=1`, `best_of=1`, `temperature=0` | жадный поиск вместо перебора 5 вариантов | ×2–3 |
| `compute_type="int8"`, `cpu_threads` = все ядра | целочисленные вычисления, максимальная загрузка CPU | ×1,5–2 |
| `without_timestamps=True` | не тратит время на токены времени | ~×1,1 |
| `condition_on_previous_text=False` | не тянет контекст между фрагментами | ~×1,1 |
| запись сразу в 16 кГц моно | нет пересчёта частоты и каналов перед распознаванием | ×1,1 |
| прямой вызов `device="cpu"` | нет потери 3–5 с на неудачную инициализацию CUDA | — |

При этом `vad_filter` **включён**: он не замедляет, а ускоряет — вырезает
паузы, и модели достаётся меньше звука. Это не «сложный VAD-фильтр», а
встроенная в faster-whisper функция (Silero VAD), один быстрый проход.

Все параметры — константы в `tutor_transcript/config.py`:

```python
MODEL_SIZE = "base"      # не менять: это требование скорости
LANGUAGE = "ru"
SAMPLE_RATE = 16_000
CHUNK_SECONDS = 30       # длительность одного фрагмента
BATCH_SIZE = 8           # сколько фрагментов за один вызов модели
CPU_THREADS = 0          # 0 = занять все ядра
```

Если на вашем компьютере 6+ ядер, можно попробовать `BATCH_SIZE = 12` —
станет немного быстрее. На 2-ядерном ноутбуке, наоборот, `BATCH_SIZE = 4`
может оказаться ровнее (меньше рывков памяти).

## 4. Проверка «всё ли работает»

Одна команда — записывает 10 секунд и сразу расшифровывает:

```
venv\Scripts\python main.py --self-test
```

В консоли появится:

* какие устройства найдены;
* сколько звука записано;
* **скорость распознавания** (например, `×24 к реальному времени`), из неё
  видно, уложится ли час в 3 минуты;
* сам текст.

## 6. Если что-то не так

| Симптом | Что делать |
| --- | --- |
| «Не хватает библиотек» | Не выполнен `pip install -r requirements.txt` — запустите `run_windows.bat` ещё раз. |
| `python` не найден | Python установлен без галочки PATH — переустановите с «Add python.exe to PATH». |
| Окно не открывается, ошибка про `tkinter` | Переустановите Python, включив «tcl/tk and IDLE». |
| В тексте только ваш голос (или только собеседник) | Проверьте в Windows «Параметры → Система → Звук», что микрофон и динамики выбраны по умолчанию. Программа пишет именно их. |
| Запись получилась тихой / «речь не распознана» | Поднимите громкость системного звука и уровень микрофона; проверьте `main.py --self-test`. |
| Расшифровка идёт дольше 3 минут на час | Смотрите строку `(×N к реальному времени)`. Если N < 20 — процессор загружен другими программами либо у него меньше 4 ядер. Закройте лишнее; при 8+ ядрах поднимите `BATCH_SIZE` до 12. |
| Первое «Расшифровка» висит дольше обычного | Скачивается модель (145 МБ). Это только первый раз. |
| Ошибка при расшифровке | Аудиозапись при этом **не удаляется** — путь к ней показан в окне ошибки, а также в журнале. Модель можно докачать и повторить позже. |
| Программа закрылась с ошибкой | Откройте `%APPDATA%\TutorTranscript\app.log` — последние строки описывают причину. |

## 7. Как устроено

```
Звук компьютера (loopback)  ┐
                            ├─► смешивание по блокам 0,2 с ─► WAV 16 кГц моно
Микрофон                    ┘                                        │
                                                                     ▼
                          faster-whisper base, int8, батчи по 8 × 30 с
                                                                     │
                                                                     ▼
                               transcript_2026-11-09_18-30-00.txt (рабочий стол)
```

* `soundcard` открывает loopback-копию динамиков и микрофон как два
  независимых «микрофона» WASAPI. Виртуальные кабели не нужны.
* Каждый источник читается в своём потоке; блоки синхронизируются по счётчику,
  поэтому рассинхронизация не накапливается даже на трёхчасовом занятии.
* Если один источник отказал (занят, отключён), запись продолжается с другим.
* Распознавание идёт в отдельном потоке — окно не подвисает.

### Тесты

```
venv\Scripts\python -m unittest discover -s tests -v
```

Звуковая карта и видеокарта не нужны: источники подменяются искусственными
сигналами, модель — заглушкой, окно — простыми объектами.
